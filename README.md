# 🤖 Two-Wheeled Gesture-Controlled Robot

A **two-wheeled mobile robot** that can be controlled in two modes:  
1️⃣ Using a **keyboard**, or  
2️⃣ Through **hand gestures** recognized by computer vision.  

The system is built within the **ROS environment** for integrated control and processing.  
A **camera** captures hand gestures, which are analyzed using **Mediapipe**, then converted into movement commands sent to the robot for real-time control.


---

## 💡 Project Overview
The main goal of this project is to combine **ROS (Robot Operating System)** with **gesture recognition** to achieve flexible robot control.  
Through Mediapipe, the system interprets hand positions and movements into directional commands, offering an intuitive and contact-free interaction method.

---

## ⚙️ Components and Parts Used
- 🧠 **ESP32** – serves as the main control and communication unit  
- ⚙️ **DC Motors** – provide motion for the two-wheel base  
- 🔌 **Motor Driver Circuit** – controls motor direction and speed  
- 🎥 **Camera** – captures the user’s hand gestures for processing

---

## 💻 Software and Tools Used
- 🦾 **ROS (Robot Operating System)** – for system integration, control, and simulation  
- ✋ **Mediapipe** – for real-time hand gesture detection via computer vision  
- 🔧 **Arduino IDE** – for programming and controlling the ESP32 module
